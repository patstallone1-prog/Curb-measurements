# Curb measurements

This repository used to publish a browser copy of the Kerbside map. That website is retired and
its files are removed. Kerbside is now an installable app, built in
[Spatial-data-mapping](https://github.com/patstallone1-prog/Spatial-data-mapping) and installed from
<https://spatial-data-mapping.vercel.app/>.

The kerb-height stereo research this repository started as lives in Spatial-data-mapping
(`src/smc/curbmeasure/`, `scripts/curbmeasure/`).
